# EISH! Khaya Lane

A small South African neighbourhood you farm and build on this device. Sow, water, harvest, place a spaza and other lane buildings, and drag them into a new spot. The spaza, workshop, and solar stand store notes for you to tap and collect. Upgrades take a short visible build. A lane level and a short goal list sit over the two skill games, which pay notes. No raids, no accounts, no real-money shop.

The earlier endless-runner builds stay in git history. They are not the game this page plays.

```sh
./build.sh
node tools/sim-runner.js
```

Open `index.html` over a local static server. Progress is saved in the browser under `eish-khaya-1`.
